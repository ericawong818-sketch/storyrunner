分享給跑友 (解決 404 問題)

點解朋友打開會 404？

因為你目前正在**開發預覽模式**，當前視窗的臨時網址（包含 preview / sandbox 字眼）已被加密保護，只有你看得到。朋友點開它會直接顯示 404 Error。

獲得正確連結的 2 個簡單方法：

  1. 方法 A（最推薦）： 直接複製你瀏覽器**最頂端網址列**（即含有專案與工作區 ID 的全網址），發給朋友，他們登入同一個工作區就能共用。
  2. 方法 B（正式發佈）： 點擊本平台右上角的 Deploy 或 Publish 按鈕將其轉為公開網站，並將發佈後的連結填在下方：
